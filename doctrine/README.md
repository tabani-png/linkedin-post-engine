# doctrine/ — the client's truth boundary and voice

Human owned. The engine reads these files and refuses to write past them. Nothing in
here is generated by a model without a human reading it afterwards.

| File | What it is | Who owns it |
|---|---|---|
| `VERIFIED-CLAIMS.md` | The allowlist. Every dollar figure, named company and scarcity phrase that may appear in a post, each with a source URL and a check date. | Human, always |
| `VOICE-PROFILE-founder.md` | Whose voice this is, measured. Generate the measured half with `scripts/ingest_voice.py`, then write the register notes a counter cannot see. | Human, from measured input |
| `config.json` | The per client thresholds and vocabularies the scorer enforces. | Human, from the voice profile |
| `PATTERNS.md` | The learnings ledger. LAW and BURNED entries are obeyed by default. | Human |
| `BODY-PATTERNS.md` | The shape shelf. One card per post, no two consecutive posts share a shape. | Human |
| `ARTIFACTS.md` | What a CTA is allowed to promise. If nothing is `status: live`, no post may promise a download. | Human |

Start by copying the two templates and the config example, then fill them in. An empty
allowlist is not a bug. It means the engine will refuse to say anything about the
client until somebody sources it, which is the correct default.

**The rule that makes the rest work:** the default answer to "can we say this?" is no.
